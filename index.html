TOKEN SETUP

Exporting 100% Pure Tokens from Figma

Open Local Variables / Tokens Studio Open your Figma file's native Local Variables panel or launch the Tokens Studio plugin.
Select Light & Dark Mode Collections Ensure both Light and Dark mode variable collections (Color, Spacing, Typography) are selected for export.
Export to JSON Payload Click Export to JSON to generate the raw tokens.json payload used by our automated pipeline.
